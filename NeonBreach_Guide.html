03

Skripty — přehled

PlayerController.cs

Hlavní ovládání hráče. Rigidbody2D pohyb, double jump, dash s energií, invincibility frames, animace.

Komponenty: Rigidbody2D, BoxCollider2D, Animator, TrailRenderer

HackingSystem.cs

Detekuje hacknutelné objekty v dosahu, spouští korutinu hackování s progress barem a glitch efektem.

Klávesa: E

HackableObject.cs

Základní třída + tři specializace: DoorHackable, LaserHackable, CameraHackable. Unity Events pro libovolné akce.

EnemyAI.cs

State machine: Patrol → Alert → Chase → Attack → Stunned. Funguje pro drony i roboty. Konfigurace v Inspectoru.

BossAI.cs

Dvě fáze, melee + ranged útoky, hacknutelné slabiny způsobující stun, transition efekt při přechodu fáze.

GameManager.cs

Singleton přetrvávající mezi scénami. Pause, game over, level loading s loading screen animací.

SecurityCamera.cs

Otáčející se kamera s detekcí pomocí Raycast. Progresivní detekce → alarm po překročení prahu.

CameraShake / GlitchEffect

Singletons pro herní efekty. CameraShake pro impakty, GlitchEffect při hackování přes shader parametr.

Level design

Level 01 — Střechy

Tutoriálový level. Pohyb, skok, první hacknutelné dveře. Minimálně nepřátel, déšť, neonové billboardy.

Level 02 — Kanalizace

Laserové pasti, pohyblivé platformy, drony v úzkých chodbách. Security kamery. Tajná místnost s upgradem.

Level 03 — Nexus Core

Boss arena. Nejprve projdi laser bludiště, pak aktivuj boss fight s NEXUS-9. Hacknutelné slabiny bossa.

Tilemap setup

Vytvoř Grid GameObject s komponentou Grid. Přidej tyto Tilemap vrstvy (pořadí od spodu):

Order | Tilemap Name | Layer | Použití 0 | Background | Background | dekorativní tapety 1 | Background_Detail | Background | trubky, kabely 2 | Ground | Ground | kolizní platfor­my (+ TilemapCollider2D) 3 | Foreground | Default | mřížky, popředí 4 | Hazards | Hazard | lasery, ostny
Tilemapě Ground přidej komponentu TilemapCollider2D + zaškrtni Used by Composite → přidej CompositeCollider2D pro optimalizovanou kolizi.
06

Krok za krokem návod

01

Vytvoř Unity projekt

Unity Hub → New Project → Universal 2D template → název "NeonBreach". Nainstaluj Unity 2022.3 LTS nebo novější.

02

Nainstaluj balíčky (Package Manager)

Window → Package Manager → nainstaluj: Cinemachine, 2D Tilemaps Editor, 2D Lights, TextMeshPro, Post Processing

Po instalaci TextMeshPro klikni na Import TMP Essentials.
03

Nastav URP Renderer pro Bloom

Project → UniversalRenderPipelineAsset → zkontroluj HDR: On. Na Main Camera přidej komponentu Volume → profil → přidej Bloom effect (Intensity ~0.8, Threshold ~0.9). Pro neonové světlo nastav barvy se saturací > 1.

04

Vytvoř Player prefab

GameObject → 2D Object → Sprite → přejmenuj "Player". Přidej komponenty:

  • Rigidbody2D — Collision Detection: Continuous, Freeze Z Rotation: ✓
  • BoxCollider2D — nastav size na postavu
  • Animator
  • TrailRenderer — pro dash trail
  • Scripty: PlayerController, HackingSystem

Přidej prázdný child "GroundCheck" a posuň ho pod nožičky. Přiřaď do pole groundCheck.

05

Cinemachine kamera

Cinemachine → Create 2D Camera → přiřaď Player jako Follow target. Nastav Dead Zone pro přirozenější pohyb. Na kameře povol Post Processing. Skript CameraShake přidej na virtuální kameru Cinemachine Impulse nebo na Main Camera Transform.

06

Tilemap level

2D Object → Tilemap → Rectangular. Otevři Tile Palette (Window → 2D → Tile Palette). Vytvoř paletu, importuj sprity tileset (Sprite Mode: Multiple, Pixels Per Unit: 32). Namaluj level.

07

Nepřátelé

Vytvoř Enemy GameObject → přidej EnemyAI.cs. V Inspectoru nastav Patrol Points (prázdné GameObjecty). Nastav sightRange, patrolSpeed, attackDamage. Přiřaď playerLayer a groundLayer.

08

Hacknutelné objekty

Přidej komponentu LaserHackable na laser objekt. Nastav laserBeam (vizuální) a laserCollider. Přidej Trigger Collider2D (Is Trigger: ✓) pro detekci hráče v dosahu. Nastav layer na Hackable.

09

Canvas HUD

Canvas → Canvas Scaler: Scale with Screen Size, Reference 1920×1080. Přidej UI elementy a přiřaď do PlayerHUD.cs. Singletons (GameManager, AlarmManager) přidej na prázdné GameObjecty v scéně.

10

Paralaxní pozadí

Vytvoř 4-5 vrstev pozadí jako SpriteRenderer GameObjecty. Na každou přidej ParallaxBackground.cs s různým parallaxMultiplier (0.1 = nejdál, 0.8 = nejblíže). Nastav Order in Layer od -5 do -1.

11

Build Settings

File → Build Settings → přidej všechny scény v pořadí: MainMenu (0), Level_01 (1), Level_02 (2), Level_03 (3), GameOver (4). Platform: PC/WebGL. Player Settings → Company Name, Product Name.

Herní systémy

  • Dash energie se automaticky regeneruje (15/s)
  • Double jump resetuje se při přistání
  • Hackování trvá 1,5s, přerušení vzdalením
  • Alarm trvá 15s, pak se sám deaktivuje
  • Checkpoint ukládá pozici, respawn s plným HP
  • Boss fáze 2 při ≤50% HP, hacknutelné slabiny → stun 4s
